# [2 인테리어 컨셉] 한 줄 결론

## 공간 (15평 ≈ 50㎡, 카페형 좌석 없음)
| 구역 | 비율 | 내용 |
|---|---|---|
| 주방 (오븐·발효·작업대) | 약 50% | 유리창으로 굽는 모습이 매장에서 보이게 → 아침 "갓 구운" 신호 |
| 아침 빵 진열 (입구 쪽) | 약 20% | 낮은 평대, 식사빵·샌드위치, 셀프 집게 → 계산대 직행 |
| 디저트 쇼케이스 (안쪽) | 약 15% | 냉장 쇼케이스 1대, 단면 진열, 한정 수량 표시판 |
| 계산·픽업 | 약 15% | 예약 픽업 선반, 벤치 1개 |

```
[입구]→ 아침빵 평대 → 계산·픽업 ← 디저트 쇼케이스
              ↑ 유리창 너머 주방(오븐) ↑
```

## 분위기 키워드
- **따뜻한 나무 + 크림색 벽 + 포인트 1색(구운 갈색)** — 아침빵(식사)과 디저트(선물) 둘 다 어울리는 중간 톤
- 조명: 아침 진열은 밝은 주광색, 디저트 쇼케이스는 따뜻한 스포트로 단면 강조
- 간판·가격표: 큰 글씨, 그림 아이콘 (시니어·아이 모두 읽기 쉽게)
