# [3 메뉴구성] 한 줄 결론
**빵 반, 디저트 반.** 아침 식사빵 8종이 매일 오는 이유를 만들고, 쫀득 디저트 8종 중 **시즌 한정 메뉴 1개를 6~8주마다 교체**해 새 손님을 데려온다.

## 왜 반반인가
- 빵(기본): 서울 빵집 매출에서 아침·60대+ 비중이 오름 → 매일 사는 식사빵이 매출 바닥을 받침 (`../0-research/findings.md`)
- 디저트(한정 메뉴): 유행 반감기 163일 → 13~17일로 짧아짐 → 디저트는 **오래 팔 생각이 아니라 돌릴 생각**으로 (`../0-research/notes/dessert_hooks.md`)
- 하계1동 빵집 객단가 13,521원 (서울 중간 10,567원) (서울시 상권분석서비스, 최근 4분기, 원/건) → 빵 1~2개 + 디저트 1개 조합이 자연스러운 동네

## 시즌 한정 메뉴 전략
**공식** (`dessert_hooks.md`): 익숙한 베이스 + 낯선 요소 하나 + 쫀득/바삭 식감 + 보이는 단면 + 희소성 + 1,500~8,000원

| 원칙 | 우리 가게에서 |
|---|---|
| 6~8주 교체 | 붐 하나가 6~10주 → 꺼지기 전에 다음 메뉴 |
| 하루 한정 수량 | 오후 2시 첫 판, "오늘 남은 개수" 표시판 (2번 공간과 연결) |
| 단면 | 쇼케이스에 반 잘라 진열 → 영상·SNS용 |
| 쫀득 + 한국 재료 | 쫀득 흐름 13개월+ 지속 → 떡·찹쌀·인절미·흑임자를 빵·구움과자에 섞음 |
| 남의 히트작 복제 X | 모방은 빠르고 원조만 남음 → 공식만 쓰고 메뉴는 직접 개발 |

## 차별화 (1번 경쟁 → 3번)
- 하계1동 빵집 8곳 중 **프랜차이즈 50%** (서울 중간 26.5%) (서울시 상권분석서비스, 2026Q2, %) → 프랜차이즈는 본사 메뉴라 6~8주 교체가 어렵다. **"동네에서 제일 먼저 새 디저트가 나오는 집"** 이 차별점
- 아침 7시 오픈 + 시니어용 부드러운 식사빵 → 프랜차이즈 평균 오픈 시간보다 빠른 아침 수요 선점 (오픈 시간 비교는 미확인)

## 원가율 (가정 — 제과점 전용 통계 미확인)
- 빵 약 30%, 디저트 약 38% → 매출 반반이면 **평균 약 34%** (기본). 비관 40.7%(외식업 2024 식재료비 비중), 낙관 30%
- 2029 외식업 식재료비 추세 연장값 46%는 상한 참고값 (`../0-research/notes/costs.md`)

## 4번에 넘길 값
- 객단가 2029 = 13,521 × 1.029³ ≈ **14,730원** (하계1동 현재 객단가 × 서울 빵집 객단가 연 +2.9%, 2021→2025)
- 원가율 34% (비관 40.7% / 낙관 30%)
- 시즌 한정 메뉴가 뜨면 매출 +20% (낙관 가정, 근거: 유행 시 줄서기 사례 — 수치 근거 약함, 가정으로 표기)

## 의외의 발견
- 사용자가 꼽은 유행 4개가 모두 **떡 계열 쫀득 식감**(두쫀쿠·버터떡·창억떡·한정선) → 2029년 빵집 디저트의 경쟁자는 다른 빵집보다 **떡집**일 수 있음. 빵에 떡 식감을 섞는 메뉴가 그 틈
