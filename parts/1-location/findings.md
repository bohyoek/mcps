# [1 입지선정] 한 줄 결론
**노원구 하계1동** — 빵집은 서울 중간값의 절반인데 점포당 매출은 1.6배, 매출은 매년 10%씩 늘고, 2027년 11월 동북선이 지나가는 동네. 가중치를 흔들어도 1,000번 중 986번 1위.

> 컨셉: 0번 후보 중 **A(아침 식사빵) 기본 + B(쫀득 화제 디저트) 교체** 조합으로 점수를 매김. 하계1동은 아침 매출 비중이 높아 A와 맞는다.

## 핵심 숫자 3개 (서울시 상권분석서비스 OpenAPI, 2026Q2 또는 최근 4분기 = 2025Q3~2026Q2)
1. **상주인구 1만 명당 빵집 3.06개** — 서울 중간값 6.28개의 절반 (`VwsmAdstrdStorW`·`RepopW`, 2026Q2, 개/1만 명)
2. **점포당 연매출 2.20억 원, 연 +10.2% 성장** — 서울 중간값 1.34억 원, −1.4%/년 (`VwsmAdstrdSelngW`, 최근 4분기, 원 / 2021→최근 4분기 연평균 %)
3. **빵집 매출 중 아침(06–11시) 26.2%** — 서울 중간값 17.5% (같은 출처, 최근 4분기, %)

## 2029년에 왜 그런가
- **동북선 2027년 11월 개통 확정**(공정률 76.4%, 2026.9) — 하계역 인근에 새 역 (`../0-research/notes/future_changes.md`, 행정동 매칭은 추정)
- 같은 노원 생활권에 **2028.7 월계동 서울원 아이파크 3,032세대·실, 2029 상반기 중계본동 백사마을 3,178세대** 입주 확정 — 인근 수요가 늘어남
- 유동인구 중 60대 이상 25.8%(서울 중간 21.5%) — 0번에서 찾은 "빵집 매출 60대+ 비중 2배" 흐름의 수혜 동네

## 점수 모델 (지표 설계의 논리성)

| 축 (가중치) | 지표 (가중치) | 방향 |
|---|---|---|
| **수요 30** | 가구수 증감률(10), 유동인구 아침 비중(10), 유동인구 60대+ 비중(5), 직장인구 증감률(5) | 높을수록 좋음 |
| **미래 변화 25** | 2027~29 확정 입주 세대(15), 2027 개통 확정 신규역(10) | 높을수록 좋음 |
| **경쟁 20** | 인구 1만 명당 빵집 수(10), 폐업률(5), 프랜차이즈 비율(5) | 낮을수록 좋음 → 뒤집음 |
| **수익성 25** | 빵집 점포당 매출(10), 빵집 매출 증감률(10), 운영 점포 평균 영업기간(5) | 높을수록 좋음 |

- **정규화:** 352개 동(빵집 5개 이상·결측 없음) 안에서 백분위(0~100). 점포 적은 동의 극단값(예: 신내2동 점포당 11.8억)에 덜 흔들리게 순위로 계산
- **정합성:** 유동인구 총량·증감률은 빼고(가구수·직장인구 증감과 겹침), 아침 비중만 씀. 빵집 아침 매출 비중은 유동인구 아침 비중과 겹쳐 점수에서 뺌(참고로만 표시)
- **가중치 이유:** 수요·수익성(각 25~30)은 "2029년에 팔리고 남는가"의 직접 근거, 미래 변화(25)는 2029년 관점의 핵심, 경쟁(20)은 0번에서 시장이 "수보다 차별화" 싸움이라 비중을 낮춤
- **민감도:** 모든 가중치를 ±30% 무작위로 1,000번 → 하계1동 1위 986회, 월계2동 14회. 하계1동·월계2동은 1,000번 모두 5위 안 (`sensitivity.csv`)
- **아직 안 넣은 것:** 동네별 임대료(API 없음) → 아래 상위 후보만 2단계에서 확인

## 의외의 발견 (인사이트)
- 예상: 2029년 유망 동네는 강남·성수 같은 지금 뜨는 곳 → 실제: **상위 3곳이 모두 노원구**. 빵집이 적고, 매출이 늘고, 확정된 교통·입주가 몰린 곳
- 예상: 빵집 많은 곳이 장사가 잘된다 → 실제: 하계1동은 빵집 밀도가 서울 중간의 절반인데 점포당 매출은 1.6배 — **공급이 수요를 못 따라가는 동네**
- 반포본동은 2027.11에 5,007세대가 들어오는데 **현재 빵집 0개·상주인구 117명**(재건축 중) → 데이터가 없어 점수에서 빠졌지만 "빈 땅" 후보로 따로 볼 가치 있음 (단 임대료 수준이 전혀 다름)
