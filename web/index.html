2. 어떤 가게인가

입지에서 손익까지 한 줄로 이어지는 컨셉

입지 → 타깃
하계1동 빵집 매출의 26.2%가 아침(06–11시, 서울 17.5%) · 유동인구 60대+ 25.8% · 서울 빵집 60대+ 매출 비중 12.2% → 21.7%
타깃 → 공간
15평 테이크아웃 · 입구엔 아침빵 평대, 안쪽엔 단면이 보이는 디저트 쇼케이스, 유리창 너머 오븐 · 턱 없는 입구와 큰 글씨 가격표
공간 → 메뉴
빵 8종 + 디저트 8종 반반 · 시즌 한정 메뉴 1개를 6~8주마다 교체 · 첫 시즌 메뉴 찹쌀 소금빵
메뉴 → 차별화
하계1동 빵집 절반이 프랜차이즈(서울 26.5%) → "동네에서 새 디저트가 제일 먼저 나오는 집" + 7시 오픈
차별화 → 손익
한정 메뉴가 통하면 매출 +20%(낙관), 안 통해도 아침빵이 바닥을 받쳐 비관에서도 흑자

디저트 유행은 점점 짧아진다

관심이 반으로 줄기까지 (언론 보도 기준 추정)

크로플 163일탕후루 54일두쫀쿠 약 15일

유행 디저트 4개(두쫀쿠·버터떡·창억떡·한정선)가 모두 떡 계열 쫀득 식감

인기 메뉴 공식

  • 익숙한 베이스 + 낯선 요소 하나
  • 쫀득하거나 바삭한 식감
  • 잘랐을 때 보이는 단면
  • 하루 한정 수량 · 개당 1,500~8,000원

의외의 발견

  1. 2029년 유망 상위 3곳이 모두 노원구 — 지금 뜨는 강남·성수가 아니다. 그곳들의 재건축은 2029년에도 공사 중.
  2. 빵집 손님이 나이 들고 있다 — 서울 빵집 매출 중 60대 이상 비중이 4년 반 만에 거의 2배 (12.2% → 21.7%).
  3. 하계1동은 빵집이 서울 중간의 절반인데 한 곳 매출은 1.6배 — 공급이 수요를 못 따라가는 동네.
  4. 임대료 차이(월 152만원)보다 매출 증가율 차이(월 540만원)가 훨씬 크다 — "싼 곳"보다 "빵이 더 팔리기 시작한 곳".
