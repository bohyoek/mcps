## 참고 자료
- **AI ROASTING 모션 디자인** https://airoasting.com/motion-design.html#cat3 — 스타일 40가지, 움직임 12원칙, 배경 음악 14가지
  - 프롬프트 뼈대: "소리 없이 자동 재생되는 N초 영상을 가로 16:9 HTML 파일 하나로. 장면·색·질감을 정하고, 모든 그림은 코드로 그리며 외부 이미지·웹사이트 UI는 넣지 않는다." + 움직임 문장 + 음악 문장
- 장면 순서·대사·숫자: `story/scenario.md` / 숫자의 근거: `story/logic.md` (여기 없는 숫자는 쓰지 않음)
- 평가 기준 05 전달력: **첫 12~15초에 결론**, 장면마다 주인공 1개

## 움직임 원칙 (12원칙 중 필수)
1. **연출** — 한 장면의 주인공은 하나. 주인공만 주황·가장 크게, 나머지는 회색·움직임 최소
2. **천천히 시작·천천히 멈추기** — 모든 이동에 가속·감속, 등속 구간 없음
3. **타이밍** — 숫자·결론은 무겁게(1.2초 이상), 보조 요소는 가볍게(0.5초 이하)
4. **예비 동작** — 큰 등장 전 반대 방향으로 살짝 물러났다 출발
5. **과장** — 장면 1의 "월 632만원"에서 **한 번만** (정점 1.3배 후 복귀)
