# 분석 범위 (행정동 단위)

A·B·C는 모든 데이터를 **아래 행정동 기준**으로 맞춥니다.
서울시 상권분석서비스의 "상권" 단위 대신 **행정동** 단위를 씁니다 — 로그인 없이 웹 화면에서 바로 조회할 수 있기 때문입니다.

| 구분 | 후보 | 행정동 | 행정동 코드 | 비고 |
|---|---|---|---|---|
| **메인** | 용산 신용산역·용리단길 | 용산구 **한강로동** | `11170625` | 한강로1가·2가 일대 |
| **비교** | 성수동 연무장길 | 성동구 **성수2가1동** | `11200670` | 연무장길이 있는 성수동2가는 두 행정동에 걸침 → 두 동을 합쳐서 분석 |

- 코드는 서울시 상권분석서비스(golmok.seoul.go.kr)에서 쓰는 8자리 행정동 코드입니다.
  - 한강로동: golmok "뜨는 상권" 화면의 용산구 지도 데이터에서 확인
  - 성수2가1동·3동: golmok의 [행정동 코드표 PDF](https://golmok.seoul.go.kr/images/adstrd_code.pdf) 기준
- 성수는 행정동이 두 개라 합계·평균을 낼 때 **어떻게 합쳤는지**(합계/가중평균)를 `findings.md`에 적어 주세요.
- 업종은 서울시 상권분석서비스의 **커피-음료 (`CS100010`)** 를 기준으로 합니다.
- 행정동은 "역 반경 500m"보다 범위가 넓습니다. 영상에서는 "○○동 기준"이라고 표기합니다.

## golmok에서 조회하는 법 (로그인 불필요)

- **지역·상권별 현황 → 지역별 현황:** 정보 분류에서 점포수, 신생기업 생존율, 평균영업기간, 개폐업수(률), 인구수, 소득/가구수, **임대시세**를 고를 수 있음 (2026-11-14 확인)
- **추정매출:** 지역별 현황 메뉴에는 없음 → **"나도 곧 사장"**(예비 창업자용) 또는 **"뜨는 상권"** 메뉴에서 지역·업종(커피-음료)을 골라 확인 (실습 때 먼저 확인할 것)
- 화면에서 숫자를 옮겨 적을 때는 **기준 분기**(예: 2026년 2분기)를 같이 적기
