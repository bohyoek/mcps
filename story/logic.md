# 결론 (1줄)
**2029년, 노원구 하계1동에 "아침빵 + 쫀득 디저트" 반반 빵집을 열면 월 632만원이 남고 22개월에 회수한다.** (기본 시나리오, 사장 인건비 전)

## 근거 1 — 왜 하계1동인가 (입지)
- 서울 352개 동 점수 모델 1위 (76.9점), 가중치 ±30%로 1,000번 흔들어도 986번 1위 (`parts/1-location/scoring.csv`, `sensitivity.csv`)
- 인구 1만 명당 빵집 3.06개(서울 중간의 절반)인데 점포당 매출 2.20억원(1.6배), 매년 +10.2% (서울시 상권분석서비스, 2021→최근 4분기)
- 2027.11 동북선 개통, 2028~29 노원 대규모 입주 6,000여 세대 (서울원 3,032·백사마을 3,178) (`future_changes.csv`)
- 임대료 3.3㎡당 8.0만원 — 서울 평균의 44% (R-ONE 상계역 상권, 2029 환산)
- **의외의 발견:** 2029년 유망 상위 3곳이 모두 노원 — 지금 뜨는 강남·성수가 아님

## 근거 2 — 왜 이 가게인가 (타깃 → 공간 → 메뉴(시즌 한정) → 차별화)
- **타깃:** 하계1동 빵집 매출 중 아침 26.2%(서울 17.5%), 유동인구 60대+ 25.8% / 서울 빵집 매출 60대+ 비중 12.2% → 21.7% (2021→2026H1)
- **공간:** 입구 = 아침빵 집어 가는 평대, 안쪽 = 단면이 보이는 디저트 쇼케이스, 유리창 너머 오븐 (15평, 좌석 없음)
- **메뉴:** 빵 8종 + 디저트 8종 반반. 시즌 한정 메뉴 1개를 6~8주마다 교체 — 유행 반감기 163일 → 13~17일 (`dessert_hooks.md`)
- **차별화:** 하계1동 빵집 절반이 프랜차이즈(서울 26.5%) → "동네에서 새 디저트가 제일 먼저 나오는 집" + 7시 오픈
- **의외의 발견:** 유행 디저트 4개(두쫀쿠·버터떡·창억떡·한정선)가 모두 떡 계열 쫀득 식감 → 빵에 떡 식감을 섞는 메뉴가 틈

## 근거 3 — 왜 남는가 (손익)
- 기본: 월 매출 2,452만원 − 재료 834 − 인건비 654 − 임대 120 − 기타 213 = **월 632만원**, 투자 1억 5,333만원 중 보증금 뺀 1억 3,797만원을 **22개월**에 회수
- 손익분기 하루 32명 (기본 예상 55명의 60%)
- 비관(매출 증가 멈춤·한정 메뉴 실패): 월 92만원 / 낙관(한정 메뉴 성공): 월 1,029만원
- **의외의 발견:** 임대료 차이(월 152만원)보다 매출 증가율 차이(월 540만원)가 훨씬 큼 → "싼 곳"보다 "빵이 더 팔리기 시작한 곳"

## 연결 점검 (컨셉의 일관성)
| 화살표 | 근거 |
|---|---|
| 입지 → 타깃 | 하계1동의 아침 매출·60대+ 비중이 서울보다 높음 → 아침 식사빵·시니어 |
| 타깃 → 공간 | 아침 손님은 빨리 집어 감 → 입구 평대 / 시니어 → 턱 없는 입구·큰 글씨 |
| 공간 → 메뉴(시즌 한정) | 단면 쇼케이스·남은 개수 표시판 → 인기 메뉴 공식의 "단면·희소성" |
| 메뉴 → 차별화 | 6~8주 교체는 본사 메뉴인 프랜차이즈(동네 50%)가 따라 하기 어려움 |
| 차별화 → 손익 | 한정 메뉴 성공 시 +20%(낙관), 실패해도 아침빵이 바닥을 받쳐 비관에서도 흑자(월 92만원) |

## 남은 약점 (발표 때 솔직하게)
- 기본 시나리오는 하계1동의 매출 증가(+10.2%/년)가 3년 더 이어진다는 가정
- 임대료는 하계1동이 아닌 상계역 상권 값(대용), 원가율·한정 메뉴 효과는 가정
